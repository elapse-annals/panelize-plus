Global Input (macOS)

Type a prompt from any app and send it to every AI in the current Panelize window. Requires the Panelize Search macOS client.

Enable global input bridge
Off by default. When on, the extension keeps a local Native Messaging connection and a periodic heartbeat so the global shortcut can send. Turn it off to stop the connection and heartbeat; quit the menu-bar app separately to stop it.
